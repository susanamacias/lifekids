# Life Kids - Oferta de Lanzamiento

Página web oficial de la oferta de lanzamiento del programa integral **Life Kids: Ciencia y Fe para Niños** (7 a 12 años).

## 📦 Contenido del Kit
- Libro Ilustrado Digital
- Fichas de Actividades y Experimentos Prácticos
- Devocionales Familiares
- Guías Pedagógicas para Padres y Educadores
- Diploma Oficial Imprimible

## 🚀 Tecnologías
- HTML5
- Tailwind CSS
- Lucide Icons
